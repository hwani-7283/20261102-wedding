# 감성 미니멀 모바일 웹 청첩장

## 실행 방법
`index.html`을 더블 클릭하면 브라우저에서 열립니다. 서버에 배포할 때는 폴더 안의 모든 파일과 폴더를 함께 업로드하세요.

## 구성
- `index.html`: 원페이지 청첩장 본문
- `css/style.css`: 모바일 디자인 및 팝업 스타일
- `js/script.js`: 사진 확대, 이전/다음 사진, 계좌 복사 팝업
- `assets/images/*.jpg`: 참고 시안에서 직접 추출한 로컬 사진 이미지

## 실제 정보로 변경하기
`index.html`에서 신랑 신부 이름, 2026년 12월 12일, 웨딩홀·주소, 부모님 이름, 계좌정보를 수정하세요.
구글 지도를 실제 장소로 연결하려면 `https://www.google.com/maps/search/?api=1&query=...`의 `query`를 원하는 장소로 바꾸세요.
현재 지도 그림은 디자인용 예시이며, 구글 지도 버튼은 강남역 검색 화면으로 이동합니다.
사진을 바꾸려면 `assets/images`의 동일 이름 파일로 교체하세요. 갤러리 버튼의 `data-photo`는 파일명과 일치해야 합니다.

## 참고
이미지는 사용자가 제공한 디자인 참고 시안에서 잘라낸 이미지입니다. 원본 시안에 인쇄된 문자·장식이 일부 포함될 수 있고, 원본 사진보다 화질이 낮을 수 있습니다. 실사용 시 원본 웨딩 사진으로 교체하는 것을 권장합니다.
